# 语音权重说明

露西的声音由两个权重文件组成。它们**不在 git 里**（单个 60–150 MB），有三条获取途径：

1. **完整版整合包** `lucy-astrbot-1.0.0-full.zip` —— 权重就在 `astrbot-plugin-lucy-voice/weights/` 里，
   解压装完即可用（插件会自动扫描，配置留空也行）；
2. Release 里单独的两个权重资产；
3. `python tools/fetch-weights.py`（下载 + 校验 SHA-256）。

| 文件 | 角色 | 大小 | SHA-256 |
|---|---|---|---|
| `lucy_v1_v5turbo_e8_s14528_l8.pth` | **音色 LoRA**（SoVITS，v5turbo，rank 8） | 66,899,835 B（63.8 MB） | `1b9ccc63f98513c25857a4954c564e85b9da113ead191ea124ead39dfd30375d` |
| `lucy_v1_v5turbo-e10.ckpt` | **GPT(s1)**（Text2Semantic，epoch 10） | 155,313,267 B（148.1 MB） | `72fa496ddcc3a3f7e30bd140134cfcc909e5371f2845ec46708aa5f1b5e1988b` |

底模不需要下载：GPT-SoVITS 整合包自带
`GPT_SoVITS/pretrained_models/gsv-v5-pretrained/s2Gv5turbo.pth`。

---

## 一、怎么拿

```bash
# 方式 A：直接点 Release 里的两个附件
# 方式 B：脚本下载 + 校验（推荐）
python tools/fetch-weights.py --dest ./weights
```

脚本会下载到 `./weights/`，并逐个比对上面的 SHA-256；不一致就报错不会留下半成品。

---

## 二、怎么用

### 自动扫描（推荐留给它自己找）

插件启动时会依次看：

```
<插件目录>/weights/                  ← 完整版整合包就放这里
<插件目录>/runtime/weights/
<AstrBot数据目录>/weights/
<AstrBot数据目录>/plugin_data/lucy_voice/weights/
```

找到 `*.ckpt` 按 `v5turbo / e10` 打分当 GPT，`*.pth` 按 `v5turbo / e8` 打分当 SoVITS（e8 优先于 e1）。
日志会打印：

```
[露西语音] 自动找到权重：gpt=lucy_v1_v5turbo-e10.ckpt sovits=lucy_v1_v5turbo_e8_s14528_l8.pth
```

配置里填了路径就以配置为准（自动发现只填空缺）。

### 插件配置

```jsonc
"tts": {
  "gpt_weights":    "D:\\weights\\lucy_v1_v5turbo-e10.ckpt",
  "sovits_weights": "D:\\weights\\lucy_v1_v5turbo_e8_s14528_l8.pth"
}
```

装的时候也可以直接传：

```powershell
python install.py --gpt-weights "D:\weights\lucy_v1_v5turbo-e10.ckpt" `
                  --sovits-weights "D:\weights\lucy_v1_v5turbo_e8_s14528_l8.pth"
```

### 对应 api_v2 的两个调用

```
GET /set_sovits_weights?weights_path=<e8 LoRA>.pth
GET /set_gpt_weights?weights_path=<e10>.ckpt
```

插件启动时会自动调（`tts.set_weights_on_init=true`）。

### ⚠️ 不要写进 yaml

`tts_infer.yaml` 的 `vits_weights_path` 必须是**底模**：

```yaml
custom:
  version: v5turbo
  vits_weights_path: GPT_SoVITS/pretrained_models/gsv-v5-pretrained/s2Gv5turbo.pth
```

把 LoRA 路径写进去会走错加载分支，产出「时长翻倍、发音崩」的残模型。
插件在 `auto_start` 时会自己生成这份只含底模的 yaml。

## 四、这套权重是怎么来的

| 项 | 值 |
|---|---|
| 框架 | GPT-SoVITS **v5turbo**（底模 `s2Gv5turbo.pth`，CFM 架构） |
| 训练素材 | 游戏官方语音 1829 条（韩语 917 + 日语 912），只保留 **KO/JA 原生文本**，不含跨语种中文标签 |
| 音色 LoRA | `rank 8`、`batch 1`、`epochs 8`；上游按音素/时长过滤后实际参与 1816 条 |
| GPT(s1) | `batch 3`、`epochs 10`，语义/音素 1829 条（过滤后 1825 条） |
| 参考音频 | 插件自带 7 条（官方日配片段），用于零样本音色锚定 |
| 输出 | 48 kHz 单声道 PCM16 |

> v5turbo **没有**独立的「turbo GPT」架构：`t2s_weights_path` 仍是 `s1v3.ckpt` 家族，
> 这份 e10 是按 v5turbo 原生数据重训的**配套** GPT，不是换了架构。

## 五、已知缺点（诚实说）

1. **中文带口音**：训练素材是韩语+日语，中文发音会偏；这正是插件让模型写日语朗读稿的原因。
2. **音色不等于游戏原声**：是 LoRA 微调的近似，换参考音频音色会偏（7 套预设就是 7 条参考）。
3. **长句会飘**：超过 200 字的一段建议切分（插件按句读自动切）。
4. **不要指望唱歌/耳语**：训练集里没有。
