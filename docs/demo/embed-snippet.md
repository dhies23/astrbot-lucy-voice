# 想要「页内播放器」时用这个模板

GitHub 会把 `<video>` / `<audio>` 标签过滤掉，仓库里相对路径的 MP4 只会变成链接。
**唯一**能让视频直接在 README 里播放的办法：在网页编辑器里把 MP4 拖进去——
GitHub 会把它上传到 `user-attachments`，插入一个形如

```
https://github.com/user-attachments/assets/14b5e180-f417-4d90-85f5-6ba1dc573546
```

的链接，这种链接才会被渲染成播放器。

## 操作步骤

1. 打开 README → 右上角铅笔（Edit）
2. 光标停在「语音示例」表格上方，把 `docs/demo/` 里的 6 个 `*.mp4` **一起拖进编辑框**
   （拖进去需要等它上传完，每条约 1–2 秒）
3. 每拖一个，GitHub 会在光标处插入一行 `https://github.com/user-attachments/assets/…`
4. 按下面的模板给每个链接补一行标题；删掉你现在看到的这些占位行

## 模板（把 `<URL>` 换成拖进来得到的链接）

```markdown
### 01 · 迎接（4.8 s）
<URL-01>

……主人回来了。饭还温着。

### 02 · 完整一轮（11.7 s）
<URL-02>

……主人回来了。饭还温着的，露西一直搁在最里面那一格。先坐下吧，露西去盛。

### 03 · 自报家门（15.7 s）
<URL-03>

露西·瓦伦汀。样品名称就是这个，PIM-001。做饭、洗衣、打扫，这些露西都会……

### 04 · 情绪 [开心]（4.0 s）
<URL-04>

第一次被主人夸了。好开心！

### 05 · 情绪 [温柔] + [停:300]（5.1 s）
<URL-05>

……请待在那里。露西去把饭热一下。

### 06 · 中文兜底（2.0 s）
<URL-06>

主人，饭已经做好了。（音色是她的，中文带口音）
```

## 不想拖也行

现在 README 里已经用了「海报图 + 链接」：缩略图是波形视频里的一帧（带播放键），
点一下打开 MP4，GitHub 的 MP4 页面自带播放器，效果和页内播放差不多，只是多一次点击。
海报图在 `docs/demo/*.poster.png`，由 `tools/make_demo_videos.py` 的产物生成。
