# 发布流程

仓库：<https://github.com/dhies23/astrbot-lucy-voice>（公开）

## 改了代码之后

```powershell
# 1. 改源码（插件在 astrbot-plugin-lucy-voice/，安装器在 release/）
# 2. 跑一遍自检
$env:PYTHONPATH="K:\AstrBot\backend\app"
K:\AstrBot\backend\python\python.exe tests\test_lucy_plugin.py

# 3. 重新打包
python build-release.py                              # 自动找权重 → 出 -full.zip（约 200 MB）
python build-release.py --weights-dir D:\weights      # 指定权重目录
python build-release.py --no-weights                 # 出精简版（约 4 MB）
# 插件单包 dist/astrbot-plugin-lucy-voice-<ver>.zip 永远不含权重（热装用）

# 4. 同步发行包到仓库的 dist/
cp dist\*.zip repo\astrbot-lucy-voice\dist\

# 5. 提交推送
cd repo\astrbot-lucy-voice
git add -A
git commit -m "…"
git push
```

> 仓库的 git 远端走 SSH（`git@github.com:dhies23/astrbot-lucy-voice.git`）。
> 如果换机器，把 `~/.ssh/id_ed25519_github` 带过去，或在 GitHub 上加一把新 key。

## 版本号要同时改三处

| 位置 | 变量 |
|---|---|
| `astrbot-plugin-lucy-voice/metadata.yaml` | `version` |
| `build-release.py` | `VERSION` |
| `release/install.py` | `VERSION` |

## 权重（Release 附件，不进 git）

| 文件 | 大小 | 怎么传 |
|---|---|---|
| `lucy_v1_v5turbo_e8_s14528_l8.pth` | 63.8 MB | `POST https://uploads.github.com/repos/dhies23/astrbot-lucy-voice/releases/<id>/assets?name=<file>`，`Content-Type: application/octet-stream`，`--data-binary @文件` |
| `lucy_v1_v5turbo-e10.ckpt` | 148.1 MB | 同上 |

上传后用 API 核对 `digest` 字段是否等于本地 SHA-256：

```
curl -s -H "Authorization: Bearer $TOKEN" \
  https://api.github.com/repos/dhies23/astrbot-lucy-voice/releases/<id>/assets
```

## 发行包为什么不进 git

当前用的细粒度 PAT 没有 **Contents: Read and write**，所以创建 Release 会被拒
（`Resource not accessible by personal access token`）。两个包先放在 `dist/` 里，
克隆仓库就能直接拿到。

想换成正式的 GitHub Release：

1. 重新生成 token，勾上 **Contents: Read and write**（或直接用带 `repo` 权限的经典 token）
2. 在 GitHub 网页 → Releases → Draft a new release，tag 填 `v1.0.0`，
   把 `dist/` 里两个 zip 拖进去即可

## 打包内容

`build-release.py` 会把这些东西塞进整合包：

```
astrbot-plugin-lucy-voice/      插件源码（含 7 条参考音频）
astrbot-plugin-lucy-voice-1.0.0.zip   插件单包（热装用）
install.py / install-lucy-astrbot.cmd / uninstall-lucy-astrbot.cmd
tools/setup_astrbot_persona.py
docs/安装说明.md（另有一份 ASCII 文件名的 INSTALL.md）
demo/japanese_sample.wav
VERSION.txt / SHA256SUMS.txt
```

## 安全

- **不要把 WebUI 密码、GitHub token 写进仓库**。测试脚本里已经改成读环境变量：
  - `LUCY_WEBUI_PASSWORD`（`tests/test_roundtrip.py`）
  - `LUCY_GSV_ROOT` / `LUCY_WEIGHTS_DIR`（`tests/test_live_tts.py`）
- 上传过的 token 建议在 GitHub → Settings → Developer settings 里轮换一次。
